#### 五条取证通道（A–E）

一条通道是一个独立取证通道，有自己的输入、判官与退出判据；它与 Release 2.0 的层名 L0/L1/L2/L3 无关。
每条通道在 M0′ 结束时要交出接入器、判官与自己的退出判据；退出判据的写法是：把这条通道关掉，
剩下的结论仍能被别的通道复算的那部分才算已经退出。

| 通道 | 输入 | 判官 | 服务的段 | 不能支持什么 | 够用判据 |
|---|---|---|---|---|---|
| A 自有历史 | 自有记录（评测前冻结成快照） | 与原始流一致：语义字段可回指到 observations | analyze/reason 与 verify | 不能证明采集面够宽；不能证明跨域泛化 | D1 通过，且同一记录重放得到相同语义字段 |
| B 自有时序事件流 | 本机正在发生的多传感器事件 | 事件捕获率 + 行为标签（labels 表，来自 pi 会话文件）【已定：labels 不进 M0′，迁移授权归 M1′】 | observe/collect | 它观察的多数时间是屏幕上的 agent 会话而不是人；不能替代用户亲自确认 | 行为标签一致率可被判官复算；事件捕获率的真值口径在 M0′ 交出时另定 |
| C 公开冻结轨迹 | 公开仓库的 issue→commit/PR→review 冻结轨迹 | 上游 CI 的机械结论 | analyze/reason 与 offer | 不能证明本地采集有效；合并率不是本产品的指标 | 每条结论都能回指上游 CI 记录 |
| D 视频/音频 | 视频与音频输入 | 产物能否构建/运行 | 观察信号：是否有人在场、是否只有播放在响 | 押后，不能支持任何接管结论 | 未定（押后，启动时另立判据） |
| E 合成/已知缺陷环境 | 注入的已知缺陷与已知答案的环境 | 已知答案，由环境本身持有 | take over | 不能证明真实任务上的接管 | 与已知 oracle 一致率 100%，任一步偏离即该次不算通过 |

### M0″ 题面 → 外部材料 → 评论（重新瞄准，取代 M0′ 的靶子）

- **目标**：一条端到端可判的表达链——**触发**（窗口/标签标题、画面变化、可见片段里的词）→
  **题面**（一句话：他在干什么）→ **外部材料**（仓库/文档/公开资料/本机会话记录，取到什么算什么）→
  **评论**（只基于取到的东西；没取到就沉默）。
- **门槛**（可观测，逐条可判）：
  1. 题面正确率：在人工标过的时间里，题面说对了"在哪个项目/哪一步"的比例（分母 ≥ 50 个时刻，由人抽样，
     不看流畅度）。
  2. 有据率：每一条出口表达都能指到它用的那份材料（路径/URL + 取的时刻）；指不到就是 0。
  3. 无材料时沉默：取不到材料的那段时间里，出口为 0 条（不是换成"我觉得"）。
  4. 错题代价：抽到的表达里"材料与题面不是一回事"的条数（阈值 0——这条比流畅度贵）。
- **不做（与"做"同等地写在这里）**：不做动作（`act` 无消费者）、不声称接管、不把屏幕像素当内容源、
  不在取不到材料时硬说话、不为这个里程碑扩五通道。
- **留下的**：M0′ 的见证层与它的证据纪律（A/C 零缺陷、可回指、重放复算）——它们是**性质**，不是靶子；
  已交的行与判据不改写。
- **作废的**："跑到 ≥200 行 VLM 小行、再抽 50 行判 B≥95%"作为主目标不再成立——它优化的是对屏幕内容的
  描述质量，而屏幕不是内容源。142 行那一轮的读数作为历史保留在下面的状态行。
- **旧 scope 问题（A 一条通道 还是 A/B/C/E 五条）不再先决**：在新方向下它不决定产品质量；
  `proc`/`fs`/`git` 降为"取题面的廉价传感器"，按需接入。
- **授权（2026-10-27）**：用户说 Proceed，替换成立。第一个材料通道只取**本机仓库 + 本机会话记录**，
  公开网络材料后接；本轮不因网络不可达而阻塞。M0″ 的机械三门必须先绿，题面正确率再交用户抽样。

### M3′ 有据的提议（dry-run，不落地）

- 门槛：可核对率 100%、埋雷捕获率 ≥80%、误杀率 ≤10%；两条按 D5/D8 判定。本里程碑不解锁任何执行权。
- 失败判据：存在无法在 5 秒内被判定的提议、埋雷没被捕获、或误杀超过门槛。

### M4a 合成环境接管闭环（先做）

- 交付：在已知 oracle 的环境里跑通 observe 到 take over 的闭环。
- 判官：已知 oracle；动作在后台进行、不阻塞用户、可回滚、留证据链。
- 门槛：与 oracle 一致率 100%、回滚准备 100%、对用户的阻塞时间 0（三项都是全称判断，逐项全对才算通过）。
- 失败判据：任一步与 oracle 不一致、动作不可回滚、或占用了用户的前台注意力。

### M4b 真实维护类接管台账（后做，30 天真实运行）

- 对象限定：用户一直欠着且有既有 check 的维护类工作——依赖、文档漂移、死链、长期红的测试、备份。
- 判官：既有 check + 事后采集的行为标签。
- 门槛：撤销率 ≤10%、无回归（既有 check 全绿）；按 D4 判定。
- 失败判据：撤销率超过门槛、既有 check 出现回归、或动作阻塞前台/不可回滚。
- 时间跨度【待用户确认】：30 天是当前记录的值。

### M5′ 公开仓库 offer（并行可选）

- 交付：对公开仓库发出的 offer，先审后发。
- 判官：上游 CI 机械通过率。
- 门槛：先审后发 100%、未审即发路径在本地伪造上游上被检出 100%、上游 CI 通过率 ≥90%
  （第三项是建议值，待真实数据校准）。
- 失败判据：任一条未经审阅就发出、未审即发路径没被检出、CI 结论回指不到上游日志；合并率不作为指标。
- 失败暴露方式：先在本地伪造上游仓库（oracle＝拒收）上跑"未审即发"路径，该路径的检出是门槛的一部分，
  不拿真实公开仓库当试验场。

## 本节点的决定账本（每条带理由与重开条件；只写"决定了什么、为什么、代价"，规则本体在别的层）

- **称呼越帧的处理：整行拒收，不做文本手术**。名字的边界在文本里不可知（词面是名词前连续汉字的后缀变体，
  最长变体会把邻词与标记词一起吞掉）；预演库里已经能看见后果：「景切换为红发」被删，连对比句标记词一起消失。
  代价是"重写历史里旧名字的行会被丢"的数量变大，杠杆在提示词。规则见 [8_DETAIL.md](8_DETAIL.md)。
- **称呼记忆要累计且不封顶**：普查量出只记上一行时 21,737 行沿用里 20,176 行拦不住；封顶 200 则旧词面被忘记，
  再写就是静默沿用（预演切片第 849 行是证据）。册子改落库表。
- **分母为 0 的项是空真**：C1 没有命中行、C2 没有被沿用行时，普查退出 2（不能确立），不记 0。空真不是通过；定义见 [2_GOAL.md](2_GOAL.md)。
- **词面放宽是**，但只放到一张**封闭的**词面表：seed 3371 的 50 行里原判据只命中 24 行，宽词面命中 47 行，
  漏掉的 23 行对比句没有任何一行被要求引用基帧。
- **判定人口是"修复之后落库的行"**，历史 104 行按已知降级保留、不回填；推翻它要一次回填 + 重抽一次样。
- **不用本地模型代跑实跑**：换模型写出的语义行不构成 B 的判定人口，还会把"修复后的行"弄脏；门槛要的实跑等产品配置。
- **标题字段化这一轮不做**：消费者是 M1′ 的基线，而它要动 observations 的写入面；重开于 M0″ 判完之后。
- **`labels` 不进 M0′**：迁移已获授权，归 M1′；文档只留一行，不建表。
- **flashdb 的静默窗优先于本轮**：它在等一个 load1 < 2 的窗口做计时读数，读错一次比晚一批判定人口更贵，
  所以本轮的实跑脚本每 tick 看有没有 flashdb 的 measure/bench 类进程（或 `/tmp/backseat-run2.yield` 哨兵），
  有就停在本轮最后一次写入、等它消失再续。让路是可见的（driver 日志一行）。
