## 用例的前提（只有指针）

所有用例只建在下面这几条已记录的事实上，原文、来源与证据住 [1_PROBLEM.md](1_PROBLEM.md) 的「谁疼」与「目标用户：可观察记录」两节：

- 使用形态：单人研究/工程工作者、全天与 agent 对话、多数时间处在 auto advance、工作时屏幕多数就是一个终端里打长段文字。
- 对话是长文本、多轮、跨天。
- 他对屏幕与“替我做”的判断：屏幕内容对他自己没什么可看的；严肃质量要靠外部材料。
- 他对“建议”的容忍度远高于“代做”。

## 用例一：终端里的长对话（主场景）

- **角色**：他，一个人，一整天在终端里跟 agent 打长文本。
- **场景**：屏幕是一个终端；文字在多轮、跨天里延续；他看得见自己打的一切。
- **流程**：触发（像素变化 / 标题变化）→ 题面（一句话：他现在在干什么）→ 外部材料（仓库、文档、公开资料、他本机的会话记录，取到什么算什么）→ 评论（只基于取到的东西）。
- **什么算完成**：这条评论说的是“系统知道而他不知道”的东西——跨时间的重复、间隔、累积、矛盾与遗忘、异常（[5_PRODUCT.md](5_PRODUCT.md) 的信息不对称原则）；四段走齐，材料真的取到了。
- **什么不算**：复述他屏幕上看得见的内容；没有材料硬凑；声称能替他动手或承诺动作（非目标住 [2_GOAL.md](2_GOAL.md)）；把 A 项目的材料贴到 B（认错题，最贵的一种错）。

## 用例二：长时间离场与回来

- **角色**：他离开机器去做别的事，多数时间处在 auto advance。
- **场景**：屏幕长时间不变、无人；他某一刻回来，接着干活。
- **流程**：离场期间没有新东西可看 → 不调模型、不说话，沉默是默认动作；回来时把这段间隔当成一次会话边界（gap_close_min，机制见 [8_DETAIL.md](8_DETAIL.md)），把离场那段折起来；第一轮就把“他现在在干什么”接上。
- **什么算完成**：离场期间一句不硬说；回来时接得上，他不用重新解释自己在做什么。
- **什么不算**：把离场/停机时长算成连续活跃；对着空画面硬说话；回来还问“你在做什么”。

## 用例三：取不到材料的时候

- **角色**：他；系统。
- **场景**：离线、被墙、仓库取不到、缓存已过期——题面有了，材料没有。
- **流程**：触发 → 题面 → 取材料失败 → 不说（沉默或降级，不编）；取不到这件事留痕（degraded_reason，字段语义见 [7_INTERFACE.md](7_INTERFACE.md)）。
- **什么算完成**：沉默就是完成；降级有据可查。
- **什么不算**：拿常识或猜测冒充材料；把过期缓存当新材料（陈旧）。

## 用例四：只有系统看得见的那些时刻

- **角色**：他；系统。
- **场景**：重复（这是第 N 次）、间隔（隔 X 天又出现）、累积（第 X 天）、矛盾与遗忘、异常——这些他自己不会去数。
- **流程**：确定性挖掘器产出候选（无 LLM）→ 人格层据此表达；无候选则沉默（含周期 digest）。
- **什么算完成**：说出口的一句能指回某条候选/某条历史（来源可查）。
- **什么不算**：没有候选仍然开口（氛围组）；复述可见内容；只用一种腔调说话（mood 单边化）。

## 用例五：次日重启后的第一次开口

- **角色**：他，隔夜回来重启。
- **场景**：昨晚的会话结束，今天屏幕上是新的东西。
- **流程**：重启 → 第一帧 → 说出“昨晚到哪了、现在在干什么”。
- **什么算完成**：答案对得上他的实际进度，且里面每个短语都能溯源到某条历史或知识（见 [5_PRODUCT.md](5_PRODUCT.md) 走查 T10）。
- **什么不算**：重启后从零开始；答案与他的实际进度对不上；把重启当成新用户。

## 预告（不是一期的用例）：二期的 CLI 询问

- **角色**：他。
- **场景**：一期纯输出，没有输入框、没有音响/麦克风、没有 STDIN；CLI 询问属二期，`ask` 是 2.2 的预览。
- **流程**：他显式问一句（例：“我今晚干了啥”）→ 按时间范围 + keys 模糊取回 → 受控合成 → 回答带引用（走查见 [5_PRODUCT.md](5_PRODUCT.md) T7）。
- **什么算完成**：回答里的每句能指向库里的条目。
- **什么不算**：把一期当成长着输入通道的产品；把 CLI 询问当对话式聊天。
