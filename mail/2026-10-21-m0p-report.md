2. **Switch clause basis** — when the row's text carries `从X切至Y`, the base frame joins that row's `obs_ids`: the frame the model names in the new `since` field (so it can be two rows back, which the D1 B review found is what actually happens), else the previous `small` row's `obs_ids`. The payload records `switch_base`. Rows without a switch clause gain nothing. The clause is detected on the model's original words, so stripping an epithet can't erase a transition.
3. **Epithet from the frame** — a standing description only survives if it is attributed to a frame this row cites: `cast=[{"name":…,"frame":n}]` with `1 ≤ n ≤` this call's image count. A description carried from an earlier row without that attribution is deleted from the text and recorded in `payload.epithet_refused`, `stats.epithet_refused` and one log line; a row whose text was nothing but the description is dropped rather than written empty; a row with **no** frame at all (`ref` NULL, evicted) refuses every person description outright. Detection is mechanical (person-noun tails + suffix variants registered in `state["epithets"]`, so `穿浅色外套的男子` and `浅色外套男子` are one description), so the mechanism works whether or not the model fills `cast`; the prompt asks for it in one added block.
